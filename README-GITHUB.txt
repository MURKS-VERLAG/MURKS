GitHub-Patch (nur Mobile)

1. Neue Datei hinzufügen:
sackit-mobile-experimental.css

2. In sack-it.html im <head> genau eine Zeile ergänzen:
<link rel="stylesheet" href="sackit-mobile-experimental.css">

3. Im linken SACKS-Menü ganz unten ergänzen:
<a class="sackit-mobile-anmeldung" href="#sackit-anmeldung">ANMELDUNG</a>

4. Dem bestehenden Anmeldebereich rechts nur id="sackit-anmeldung" geben.
