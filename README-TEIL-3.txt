# MURKS – Teil 3 Charaktere

Enthält den Ordner:

assets/characters/

Mit den Figuren für den Bereich `Die Säcke`.

## Upload

1. ZIP entpacken.
2. Den Ordner `assets` in GitHub hochladen.
3. Vorhandene Ordner ergänzen/ersetzen lassen.
4. `Commit changes` klicken.
5. Actions grünen Haken abwarten.
6. Website öffnen:
   https://murks-verlag.github.io/MURKS/
